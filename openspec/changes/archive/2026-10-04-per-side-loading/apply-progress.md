## Deviations and discoveries
- **The web never changed a bar weight before.** "Correct the bar weight…" previewed the unchanged stored bar. "Change the bar weight" now saves through PUT and then opens the preview.
- **The mappers read a null bar as 0 g.** In the API set mapper and the IndexedDB queue that would have crashed `LoggedSet.restore` for a no-bar set; it is fixed and pinned by the shared repository contract.
- **Done sets keep their raw grams** and are labelled at render time, so a kg/lb switch relabels history.
